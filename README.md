# Rust для Solana-разработчика

Учебная CLI-программа без внешних зависимостей. Имитирует перевод SOL между аккаунтами Aidos (10 SOL) и Aliya (2 SOL). Работает локально, без подключения к Solana; суммы заданы в целых SOL.

## Конструкции Rust

- `struct Account` — адрес и баланс аккаунта.
- `enum TransferError` — ошибки перевода.
- `impl` — создание аккаунта и получение сообщения об ошибке.
- `Result` и `match` — возврат и обработка результата операции.
- Функции — чтение ввода, перевод средств и вывод результата.
- `&mut Account`, `&self`, `&str` — ссылки и заимствование.
- `loop` — повторные переводы до выхода из программы.

Перед переводом проверяются положительная сумма, достаточность баланса, различие адресов и отсутствие переполнения. При ошибке балансы не меняются.

## Запуск

Требуются Rust и Cargo. Из папки с `Cargo.toml` выполнить:

```sh
cargo run
```

В меню выбрать `1` (Aidos → Aliya) или `2` (Aliya → Aidos), затем ввести сумму в целых SOL. После операции снова появится меню. Для выхода выбрать `0`.

Балансы сохраняются между переводами до выхода из программы. При новом запуске начальные балансы восстанавливаются. Некорректный ввод выводит сообщение об ошибке и возвращает в меню.

## Успешный перевод

Выбрать `1`, затем ввести `3`. Результат:

```text
Перевод: Aidos -> Aliya
Сумма перевода: 3 SOL
Перевод выполнен успешно.
Баланс отправителя: 10 -> 7 SOL
Баланс получателя: 2 -> 5 SOL
```

## Пример ошибки

Выбрать `1`, затем ввести `20`. Результат:

```text
Перевод: Aidos -> Aliya
Сумма перевода: 20 SOL
Ошибка: Недостаточно средств на балансе отправителя.
Балансы не изменились.
```
